# IPL Score Predictor (NumPy Project)

This project predicts the IPL score of a team using NumPy. 
It analyzes previous match scores and calculates:

- Average score
- Highest and lowest score
- Standard deviation
- Outlier detection
- Score prediction using:
  - Simple average
  - Weighted average
  - Monte Carlo simulation

# How to Run
1. Install Python on your system.
2. Open the terminal inside the project folder.
3. Run the command:
   python ipl_score_predictor.py

# Output
The program will display:
- Basic statistics
- Outliers
- Score predictions
